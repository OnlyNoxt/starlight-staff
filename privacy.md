Starlight Staff — Privacy Policy

Last updated: October 14, 2026

1. Overview

Starlight Staff is a Discord bot used to manage community support, forms, and administrative features for the Starlight server.

2. Information Processed

Depending on enabled features, the bot and its service provider may process:

* Discord user and server identifiers
* Support ticket messages and responses
* Application form submissions
* Bot command interactions
* Server configuration and related activity data

3. How Information Is Used

Information is processed to provide requested features, manage support requests, review applications, maintain community operations, and address abuse.

4. Service Providers

Starlight Staff is powered by Appy, which may process information necessary to operate the bot. Appy’s Privacy Policy is available at https://appy.bot/privacy-policy.

5. Data Access and Retention

Authorized server administrators may access information submitted through configured administrative features. Retention and deletion depend on the enabled features, administrator actions, and Appy’s data handling practices.

6. Data Requests

Users may contact Starlight server administrators to request information about data access or deletion. Some requests may need to be directed to Appy.

7. Security

The server administration team will use available access controls to limit access to administrative information.

8. Changes

This policy may be updated to reflect changes in the bot’s features or data practices.

9. Contact

Privacy questions may be directed to the Starlight server administration team through the server’s designated support channel.
